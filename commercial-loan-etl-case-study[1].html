Business challenge

Loan-level CSV data can contain repeated records, inconsistent rate and currency formatting, and mismatched status labels. These issues can distort reporting and prevent reliable downstream analysis. This project uses a fictional commercial loan dataset to demonstrate an end-to-end ETL workflow with data-quality controls.

Pipeline architecture

CSV source → SSIS Flat File Source → SQL Server staging → T-SQL transformation & validation → clean portfolio table → reconciliation

The SSIS Control Flow executes three tasks in order: Clear Loan Portfolio Staging; Extract CSV to Loan Staging; Transform and Load Clean Loan Portfolio.

Transformation and quality controls

  • Removed one exact duplicate record while retaining four unique loan IDs.
  • Converted currency-formatted balances into numeric values.
  • Converted percent strings into decimal interest rates.
  • Standardized source status values such as ACTIVE and Current to Active.
  • Checked loan IDs, borrower names, balances, rates, and status values for quality exceptions.
  • Reconciled record counts, distinct loan IDs, duplicate counts, and portfolio balances.

Verified outcome

SQL verification showed four clean records, four distinct loan IDs, no duplicate IDs, and a total loan balance of $875,000. The SSIS package completed successfully on two runs using the same sample input, demonstrating repeatability for this test case.

Technical troubleshooting

Resolved CSV parsing of quoted currency values, SSIS flat-file column width and destination mappings, SQL Server connection settings, and an Execute SQL Task preparation issue. These corrections enabled all three Control Flow tasks to complete successfully.

Skills demonstrated

SSIS Control Flow and Data Flow · SQL Server staging · CSV ingestion · T-SQL CTEs · data cleansing · type conversion · deduplication · validation · exception handling · portfolio reconciliation · repeatable ETL execution.

Scope and publication note

This is an educational simulation with fictional data, not a production bank integration. The accompanying portfolio SQL files are reconstructed, reviewable examples based on the verified project rules; they should not be described as exact exports of the original working SSIS SQL tasks.
